# Cloudflare Pages deployment

The generated static site lives in `site/`.

## Git integration

Recommended settings:

- Production branch: `main`
- Build command: `ruby scripts/build_site.rb --reports report-preview --out site`
  for preview-only deployments, or point `--reports` / `--evidence` at the
  evidence generated by the acceptance run.
- Build output directory: `site`

For a release/evidence deployment, generate the reports first and then run
`build_site.rb` against that evidence directory.

## Direct upload

With Wrangler available:

```bash
npx wrangler pages deploy site \
  --project-name rails8-ai-image-processing-api-community-acceptance-kit
```

The `wrangler.toml` at repository root declares `site/` as the Pages build
output directory.
